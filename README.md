# Running Simulater

Unity로 만든 러닝 게임 "도심속 달리는 떠돌이 개"입니다.

## 필요 에셋
이 저장소에는 아래 에셋이 포함되어 있지 않습니다. 프로젝트를 열기 전에 직접 설치해 주십시오.

| 에셋 | 설치 경로 | 받는 곳 |
|---|---|---|
| DOTween (HOTween v2) | `Assets/Plugins/Demigiant/` | [Unity Asset Store](https://assetstore.unity.com/packages/tools/animation/dotween-hotween-v2-27676) |

설치 후 `Tools > Demigiant > DOTween Utility Panel > Setup DOTween...`을 한 번 실행해 주십시오.

## 빌드
Windows 빌드는 [Releases](../../releases)에서 받을 수 있습니다.
